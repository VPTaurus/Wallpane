Rows and columns

Your tiles move into the new frames in reading order; frames left over become empty tiles, ready for media or a playlist.

Frame layouts
Your layouts

A layout moves your current tiles into new frames, keeping their order from left to right and top to bottom. It does not change which media you have.

Saved walls

A saved wall keeps the grid, each tile's place and settings, and the path of each file. The files stay where they are. If a file has moved, its tile shows "File not found" and you can locate it.

Folder playlist

These options are for new playlists. To change one that is already playing, right-click one of its tiles and choose Playlist settings.

A folder playlist fills the empty cells, one file per tile. When a clip ends, or an image has been shown long enough, the tile takes the next file. Cells you add later fill too, and new files in the folder join the queue. Drop a folder on one tile (or use Own folder in the side panel) to give just that tile the folder. On a tile, the skip button moves on and the pin keeps the current file.

Getting started
  • Add media with the Add button, or drop files and folders from Explorer. Drop on a tile to replace it.
  • Drag a tile to move it; tiles in the way make room. Drag any border or corner to resize.
  • Right-click a tile for everything you can do with it, including Properties (exact position and size). Right-click empty wall to add media or a new empty tile there.
  • For sizes in between cells, switch to Free (pixels). Shift keeps a tile's shape while you resize it.
  • Scroll over the selected tile to zoom its media; Reposition and zoom lets you drag the media inside the tile.
  • Wall mode shows only the wall, on the display you pick in Settings.

About

Wallpane

Wall mode
Startup

For a wall that runs on its own, turn on both start options: the wall comes back full screen after a restart. Esc or F11 leaves wall mode.

Windows

Each window has its own wall, for example one per monitor. Saved walls and frame layouts are shared.
