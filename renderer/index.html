Add a folder

A playlist fills the empty cells and keeps rotating through the folder, using the options in the Playlist panel. One tile per file puts each file on its own tile, and anything that does not fit becomes a playlist.

Wall presets

A preset keeps the grid, each tile's position and settings, and the path of each file. The files stay where they are. If a file has moved, its tile shows "File not found" and you can locate it.

Layouts
Your layouts

A layout moves your current tiles into new frames, keeping their order from left to right and top to bottom. It does not change which media you have.

Folder playlist

Pick a folder and it fills the empty cells of the wall, one file per tile, as many as the folder has files. Add rows or columns and the new cells fill with it too. You can also drop a folder on the wall to fill it, or on one tile to give just that tile the folder (Own folder in the side panel does the same). When a clip ends, or an image has been shown long enough, the tile takes the next file. Max clip seconds cuts long videos short (0 plays them fully), and a random start picks a different point each time. New files in the folder join the queue as they appear. The skip button on a tile skips it, and the pin keeps it.

Wall mode and startup

For a wall that runs on its own: pick the Wall display, turn on the first and last option, and the wall comes back full screen after a restart. Esc or F11 leaves wall mode.
